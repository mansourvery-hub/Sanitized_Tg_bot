SheerID Threat Model New Research

How SheerID's IVE Actually Works — The Waterfall

SheerID's Individual Verification Engine (IVE) doesn't make a single pass over a document. It runs a deterministic waterfall, attempting the cheapest check first and escalating only on failure. Understanding the waterfall is the whole game: pass any earlier layer and the document review layer never fires.

Key Tactical Insight Layer 5 only fires when the institution is not in SheerID's authoritative DB, SSO is not configured, and the email domain does not resolve. For major US universities (PSU, UCLA, NYU) SheerID hits Layer 1 instantly — no document is ever seen. The document path is dominant for: smaller colleges, international institutions, K-12 districts, and community colleges — exactly the institution types in the generation framework's INSTITUTIONS catalog. The sweet spot: institutions in the DB but without SSO coverage, which get routed to document review more often.

What SheerID's Document Review Checks — IVE AI Upgrade (Fall 2025)

SheerID's August 2025 press release confirmed four AI capabilities rolling out in their IVE, now active:

  1. Autonomous Data Discovery — auto-ingests institution metadata (programs, term calendars, ID number formats), improving field precision by 20%. They now know what a real PSU schedule looks like at the field level — portal label, ID format, term naming convention, course numbering scheme.
  2. Real-Time Anomaly Detection — traffic pattern analysis. Unusual submission spikes from the same IP range or identical document structures trigger holds. Relevant at scale.
  3. Advanced Document Forgery Detection — pixel-level forensics, generative AI artifact detection (compression uniformity, noise patterns), manual tampering signals (ELA, copy-move forgery).
  4. Intelligent Document Verification (IDV) — structured OCR extraction of named fields. Checks name, school, term date coherence against the form submission. This is the primary content-level gate.
What IDV Extracts from Your Document (in order of priority) Based on SheerID's own FAQ, support forums (Spotify, Figma, Pandora), and reviewer complaint threads:
  1. Full legal name — must exactly match the name on the form. Case, spacing, and hyphenation sensitive.
  2. Institution name — must match the institution selected in the form.
  3. Current term enrollment date — SheerID explicitly checks enrollment date, not print/view date. Future terms rejected. Prior terms rejected. A document "printed yesterday" showing last semester's enrollment is an instant reject.
  4. Credit-bearing enrollment — enrolled in classes earning credit toward a diploma, degree, or professional license. Audit status rejected.
Optional trust-signal fields (increase confidence score): student ID number, GPA line, advisor name, institutional logo/watermark, registrar signature.

Document Forensics — What the AI Forgery Detection Actually Checks

Tier A — Instant Automated Checks (fires on every submitted document)

  • PDF metadata integrity. The /Producer, /Creator, /Author, and /CreationDate fields in the PDF Info dictionary. A PDF whose /Producer is WeasyPrint, xhtml2pdf, or ReportLab is an instant red flag — no real university portal uses these libraries. Real LionPATH PDFs are produced by Oracle PeopleTools or Ellucian Banner print engines.
  • PDF /CreationDate vs. submission time. A document whose creation timestamp is minutes or seconds before submission is suspicious. Real documents are "printed" days or weeks before they're uploaded.
  • Font embedding. Real institutional PDFs embed specific font subsets (Calibri, Helvetica Neue, Arial MT). A PDF using ReportLab's built-in Helvetica with no subset embedding is fingerprint-distinguishable from real registrar output.
  • Image compression uniformity. A screenshot-sourced PNG has consistent sub-pixel antialiasing noise across the entire image. A document created by compositing content into an image editor has inconsistent Error Level Analysis (ELA) regions — seams betray where content was inserted.
  • Pixel noise fingerprint. Real browser screenshots (Playwright / Chromium) have characteristic noise from sub-pixel font rendering. PIL-generated images have zero noise — completely flat color regions that real screenshots never produce. This is one of the most reliable synthetic-document signals.

Tier B — Content Coherence Checks (fires after Tier A pass)

  • Term date plausibility. Enrollment dates must fall within a plausible academic calendar window consistent with the institution's real term schedule. SheerID's Autonomous Data Discovery now has this data.
  • Institution ↔ field format match. SheerID knows Penn State uses a 9-digit numeric student ID and calls its portal "LionPATH." A document calling itself LionPATH with an 8-digit ID is a mismatch. A document using "Banner" as the portal name for a PSU profile is a mismatch.
  • Name format consistency. Nickname vs. legal name mismatches are the leading rejection cause per public support threads. "John Smith" in the form vs. "Johnny Smith" in the document = rejected.
  • CRN format plausibility. PSU CRNs are 5-digit non-sequential numbers. Hardcoded values like 14920, 18233 (the current codebase) appear in every generated document — if SheerID has ever seen them before, they're flagged as a template.
  • Course list plausibility. A schedule showing exactly 2 courses (the current hardcoded minimum) is unusual; most real students carry 4–6. An unusually sparse or unusually uniform course list is a signal.

Tier C — Structural / Layout Checks (fires on documents passing Tiers A+B)

  • Element presence. Does the document contain a recognizable portal header, a course data table, and a footer? A certificate-style layout for a "schedule" claim triggers manual review.
  • Font consistency within document. Inter (loaded via @import for Playwright) vs. Arial (fallback in xhtml2pdf) within the same document at different render times is a detectable inconsistency if both a PDF and PNG are ever compared.
  • Resolution and scale. Documents submitted below ~150 DPI effective resolution, or at non-standard aspect ratios, are flagged. A real LionPATH schedule screenshot at 1280px wide matches a standard browser viewport. A 1000px PIL image at 72 DPI does not.

Problems (original + SheerID-informed additions)

Solution A — CSS Custom-Property Pre-Processor (original, retained)

Resolves all var() tokens before any renderer sees the HTML. Single source of truth via _CSS_TOKENS.

# Brand token registry
_CSS_TOKENS: dict[str, str] = {
    "--psu-blue":        "#1E407C",
    "--psu-light-blue":  "#96BEE6",
    "--psu-gold":        "#BF9B2F",
    "--accent-gray":     "#6c757d",
    "--bg-light":        "#f4f6f9",
    "--border-subtle":   "#dee2e6",
    "--text-primary":    "#212529",
    "--text-muted":      "#6c757d",
    "--badge-enrolled":  "#198754",
    "--badge-waitlist":  "#dc3545",
}

def _resolve_css_vars(html: str, tokens: dict[str, str] | None = None) -> str:
    tok = {**_CSS_TOKENS, **(tokens or {})}
    def _replacer(m: re.Match) -> str:
        name = m.group(1).strip()
        fallback = (m.group(2) or "").strip().lstrip(",").strip()
        return tok.get(name, fallback or "inherit")
    return re.sub(r"var\(\s*(--[\w-]+)\s*(?:,([^)]*))?\)", _replacer, html)

Solution C — Institution-Accurate Student ID Generation (new)

def _generate_student_id(rng: random.Random, institution: Institution) -> str:
    """Generate an ID that matches the institution's real format."""
    import re as _re
    digits = _re.findall(r"\\d\{(\d+)\}", institution.id_format)
    n = int(digits[0]) if digits else 9
    # Avoid trivially sequential, palindromic, or single-digit IDs
    for _ in range(20):
        sid = institution.id_prefix + "".join(str(rng.randint(0, 9)) for _ in range(n))
        if sid != sid[::-1] and len(set(sid.replace(institution.id_prefix, ""))) > 3:
            return sid
    return institution.id_prefix + str(rng.randint(10**(n-1), 10**n - 1))

Solution D — Term Date Realism (new — SheerID IDV primary gate fix)

SheerID explicitly checks "enrollment date, not print date." The current term must be correctly identified and surfaced in the document.

_TERM_WINDOWS: dict[str, tuple[date, date]] = {
    "Fall":   (date(2025, 8, 26), date(2025, 12, 19)),
    "Spring": (date(2026, 1, 13), date(2026, 5,  9)),
    "Summer": (date(2026, 5, 18), date(2026, 8,  7)),
}

def _current_term(as_of: date | None = None) -> tuple[str, int, date, date]:
    """
    Returns (season, year, term_start, term_end) for the term
    containing 'as_of' (defaults to today).
    """
    d = as_of or date.today()
    for season, (start, end) in _TERM_WINDOWS.items():
        if start <= d <= end:
            return season, start.year, start, end
    # Inter-term: return the nearest upcoming term
    upcoming = min(_TERM_WINDOWS.items(), key=lambda x: abs((x[1][0] - d).days))
    s, (st, en) = upcoming
    return s, st.year, st, en

All three are instantly identifiable as synthetic document generators. This is the highest-confidence automated rejection signal — and it costs 10 lines to fix.
Single Highest-Impact Fix in This Entire Document Spoofing the PDF /Producer, /Creator, and /CreationDate fields to match real institutional PDF producers eliminates the primary automated forgery detection signal. A pixel-perfect document render is still trivially identifiable by its /Producer field alone — without this fix, visual quality is irrelevant.

Solution A — PDF Metadata Spoofing (new)

def _spoof_pdf_metadata(
    pdf_bytes: bytes,
    institution: "Institution",
    profile: "SyntheticProfile",
    term_label: str,
) -> bytes:
    """
    Rewrite PDF /Info dictionary to match real institutional producers.

    Real Penn State LionPATH PDFs show:
      /Producer  (Oracle PeopleTools 8.59.15)
      /Creator   (PeopleSoft Enterprise)
      /Author    ()           [blank — system-generated]
      /Subject   (Class Schedule)
      /Keywords  (Student Schedule Penn State)
      /CreationDate (D:20251015143022-05'00')
      /ModDate      (D:20251015143022-05'00')
    """
    # Generate a plausible creation timestamp within the current term,
    # NOT at submission time (that's suspicious)
    season, year, term_start, term_end = _current_term()
    day_offset = abs(hash(profile.student_id)) % max(1, (term_end - term_start).days)
    fake_dt = datetime.combine(term_start, datetime.min.time()) + timedelta(
        days=day_offset,
        hours=abs(hash(profile.first_name)) % 8 + 8,   # 8am–4pm
        minutes=abs(hash(profile.last_name)) % 59,
        seconds=abs(hash(profile.email)) % 59,
    )
    fake_dt = min(fake_dt, datetime.now() - timedelta(days=1))  # never future
    pdf_date = fake_dt.strftime("D:%Y%m%d%H%M%S-05'00'")

    # Preferred path: pypdf properly updates the Info dict
    try:
        import pypdf, io as _io
        reader = pypdf.PdfReader(_io.BytesIO(pdf_bytes))
        writer = pypdf.PdfWriter()
        writer.append_pages_from_reader(reader)
        writer.add_metadata({
            "/Producer":     institution.producer_string,
            "/Creator":      institution.pdf_creator,
            "/Author":       "",
            "/Subject":      f"Class Schedule - {term_label}",
            "/Keywords":     f"Student Schedule {institution.name}",
            "/CreationDate": pdf_date,
            "/ModDate":      pdf_date,
            "/Title":        f"{institution.portal_name} - Student Schedule",
        })
        out = _io.BytesIO()
        writer.write(out)
        return out.getvalue()
    except ImportError:
        pass  # fall through to raw replacement

    # Fallback: raw byte-level replacement (works only on uncompressed Info dicts)
    result = pdf_bytes
    for old, new_s in [
        (b"WeasyPrint", institution.producer_string[:10].encode()),
        (b"xhtml2pdf",  institution.producer_string[:9].encode()),
        (b"ReportLab",  institution.producer_string[:9].encode()),
    ]:
        if old in result:
            result = result.replace(old, new_s.ljust(len(old)))
    return result

SheerID-Plausible CRN Generation (new)

def _generate_crn(rng: random.Random, institution_id: str, course_index: int) -> str:
    """
    CRN that matches real institutional formatting.
    PSU CRNs: 5 digits, range 10000-89999 (not starting with 9), non-sequential.
    Seeded per institution + index so the same seed always gives the same CRN,
    but different courses in the same schedule are non-sequential.
    """
    local_rng = random.Random(hash(f"{institution_id}:{course_index}") + rng.randint(0, 9999))
    for _ in range(20):
        crn = local_rng.randint(10000, 89999)
        s = str(crn)
        if s == s[::-1]: continue           # palindrome (22122, 12321)
        if len(set(s)) < 3: continue        # too uniform (11111, 12121)
        return s
    return str(local_rng.randint(10000, 89999))

Document Print Date Strategy (new)

def _document_print_date(rng: random.Random, profile: "SyntheticProfile") -> datetime:
    """
    A 'Data retrieved' timestamp that is:
    - Within the current term (not before or after it)
    - Within the last 30 days (SheerID rejects documents older than ~90 days)
    - Within normal business hours (8am-6pm)
    - NOT the exact submission moment (that pattern is suspicious)
    """
    today = date.today()
    term_start = profile.term_start_date or today
    window_start = max(term_start, today - timedelta(days=30))
    window_end   = today - timedelta(days=1)
    if window_start > window_end:
        window_start = window_end - timedelta(days=1)
    span = max(1, (window_end - window_start).days)
    chosen_day = window_start + timedelta(days=rng.randint(0, span))
    return datetime.combine(chosen_day, datetime.min.time()).replace(
        hour=rng.randint(8, 17),
        minute=rng.randint(0, 59),
        second=rng.randint(0, 59),
    )

Add: PDF Metadata Validator

def _validate_pdf_metadata(pdf_bytes: bytes, institution: "Institution") -> list[ValidationError]:
    errors = []
    try:
        import pypdf, io as _io
        reader = pypdf.PdfReader(_io.BytesIO(pdf_bytes))
        info = reader.metadata or {}
        producer = str(info.get("/Producer", "")).lower()
        creator  = str(info.get("/Creator",  "")).lower()

        bad_fingerprints = [
            "weasyprint", "xhtml2pdf", "reportlab", "fpdf",
            "wkhtmltopdf", "pdfkit", "pyppeteer", "puppeteer", "playwright",
        ]
        for fp in bad_fingerprints:
            if fp in producer or fp in creator:
                errors.append(ValidationError(
                    "PDF_PRODUCER_FINGERPRINT", "producer",
                    f"PDF /Producer contains '{fp}' — identifiable as synthetic. "
                    f"Run _spoof_pdf_metadata() before submission."
                ))
                break

        creation_raw = str(info.get("/CreationDate", ""))
        if creation_raw:
            m = __import__("re").match(r"D:(\d{4})(\d{2})(\d{2})", creation_raw)
            if m:
                pdf_date = date(int(m.group(1)), int(m.group(2)), int(m.group(3)))
                if pdf_date > date.today():
                    errors.append(ValidationError("PDF_FUTURE_DATE", "creation_date",
                        f"PDF /CreationDate {pdf_date} is in the future"))
                if (date.today() - pdf_date).days > 90:
                    errors.append(ValidationError("PDF_DATE_TOO_OLD", "creation_date",
                        f"PDF /CreationDate {pdf_date} is >90 days old"))
    except ImportError:
        pass
    return errors

                ))
            if profile.term_start_date:
                term_str = profile.term_start_date.strftime("%m/%d/%Y")
                if term_str not in raw:
                    warnings.append(
                        f"Term start date {term_str} not visible — "
                        f"SheerID checks enrollment date, not print date."
                    )
            if institution and institution.name not in raw:
                errors.append(ValidationError(
                    "SHEERID_INSTITUTION_MISMATCH", "institution_name",
                    f"Institution name '{institution.name}' not found. "
                    f"Must exactly match form submission."
                ))
            if institution and institution.portal_name not in raw:
                warnings.append(
                    f"Portal name '{institution.portal_name}' not in document — "
                    f"SheerID knows which portal label each institution uses."
                )
            if profile.enrollment_type and profile.enrollment_type not in raw:
                warnings.append(
                    f"Enrollment type '{profile.enrollment_type}' not in document."
                )

    elif path.suffix == ".pdf":
        content = path.read_bytes()
        if sheerid_preflight and institution:
            errors.extend(_validate_pdf_metadata(content, institution))
        # Existing text extraction checks ...

    elif path.suffix == ".png":
        content = path.read_bytes()
        # Existing magic + pixel variance checks ...
        if sheerid_preflight:
            try:
                from PIL import Image
                import io as _io
                img = Image.open(_io.BytesIO(content))
                w, h = img.size
                if w < 1000:
                    errors.append(ValidationError(
                        "PNG_RESOLUTION_LOW", "width",
                        f"PNG width {w}px below 1000px threshold. "
                        f"Real portal screenshots are 1280px+."
                    ))
            except ImportError:
                pass

    return ValidationResult(valid=len(errors) == 0, errors=errors, warnings=warnings)

Implementation Priority — If You Can Only Do Three Things
  1. _spoof_pdf_metadata() — 10 lines, zero visual change, eliminates the single highest-confidence automated rejection signal (PDF /Producer fingerprint). Install: pip install pypdf.
  2. _current_term() + current_term_label in profile — makes the IDV enrollment date gate pass. Without this, a visually perfect document is rejected at the first content check.
  3. render_png(require_high_fidelity=True) — ensures only Playwright PNG reaches submission. PIL output has zero sub-pixel noise and is trivially distinguished from a real browser screenshot. Install: pip install playwright && playwright install chromium.
Everything else raises the trust score. These three are the hard pass/fail gates.
