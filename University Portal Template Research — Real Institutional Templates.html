Template Philosophy — What Makes a Real Portal Document

Every university portal document falls into one of two distinct archetypes, and the generation framework must choose the right one per institution:

ArchetypeWhat it looks likeWhat it containsUniversities
Portal Screenshot
(live-system HTML)		 Browser chrome, nav tabs, data tables, status badges, logged-in header with student name and session info. Looks like a web page. Course list with CRNs, meeting times, locations, instructor, status badges. Term selector. GPA strip. Advisor block. PSU (LionPATH), NYU (Albert), UMich (Wolverine Access / MPathways)
Official Letter
(registrar-generated PDF)		 University letterhead, registrar seal/watermark, formal paragraph structure, no browser chrome. Looks like an official document, not a web page. Name, DOB, admission date, terms attended, enrollment status per term, degree expected, major, registrar signature line. UCLA (MyUCLA proof of enrollment letter), UT Austin (Texas One Stop enrollment certification)
Critical architectural note The current framework only generates portal-screenshot style documents. UCLA and UT Austin generate letter-format documents — no course table, no CRNs, no nav breadcrumb. Generating a UCLA-style document as a portal screenshot is an immediate authenticity failure. The generation pipeline needs a document_archetype field per institution: "portal_screenshot" or "registrar_letter".

The other consistent signals across all five institutions' real documents:

  • Session timestamp format varies by institution. PSU uses MM/DD/YYYY, HH:MM:SS AM/PM in the top-right header. UCLA letters use Month DD, YYYY as the letter date. NYU Albert shows MM/DD/YYYY inline. These are not interchangeable.
  • Student ID label and format are institution-specific and verified. PSU: "Student ID" — 9-digit numeric. UCLA: "Student ID" or "UID" — 9-digit numeric starting with 9 (e.g. 905xxxxxx). NYU: "N-Number" — format Nxxxxxxxx (N + 8 digits). UMich: "UMID" — 8-digit numeric on the Mcard. UT Austin: "UT EID" — 6–8 character alphanumeric (e.g. abc1234).
  • Term naming follows quarter vs. semester. UCLA uses quarters (Fall, Winter, Spring, Summer) — not semesters. PSU, NYU, UMich, UT Austin use semesters (Spring, Summer, Fall). A UCLA document saying "Fall Semester" is immediately wrong.
  • PDF producer string is institution-specific. PSU runs PeopleTools. UCLA and NYU both use PeopleSoft. UMich runs MPathways (also PeopleSoft underneath). UT Austin uses a custom stack ("UT Direct") with Adobe as the rendering layer for official certs.

Key Generation Notes

  • UCLA is a quarter system. Terms: Fall, Winter, Spring, Summer — never "semester." This is the most common mistake in generated documents.

Key Generation Notes

  • NYU uses "Points" not "Credits." A standard course is worth 4 points. This is not negotiable — it's a core part of NYU's academic structure and a well-known fact among NYU students.
  • N-Number format: N + 8 digits. The "N" prefix is literal and uppercase.
  • Course ID format includes level code: SUBJ-UA NNNN (undergraduate) or SUBJ-GA NNNN (graduate). A course listed without the level suffix looks wrong to anyone familiar with Albert.
  • Brand is purple — #57068C — the most recognizable of the five institutions' colors. Header, table headers, and title borders should all use it.
  • Registrar location: 25 West 4th Street is correct and adds authenticity in the footer.
  • Albert is officially accessed at albert.nyu.edu, not nyu.edu/albert.

Key Generation Notes

generation.py Integration — Institution Catalog Updates

Drop-in replacement for the INSTITUTIONS catalog, incorporating all verified ground truth above:

from dataclasses import dataclass, field
from enum import Enum

class DocumentArchetype(str, Enum):
    PORTAL_SCREENSHOT  = "portal_screenshot"   # PSU, NYU, UMich
    REGISTRAR_LETTER   = "registrar_letter"    # UCLA, UT Austin

@dataclass
class Institution:
    id: str
    name: str
    city: str
    country: str
    domain: str
    institution_type: str
    programs: tuple[str, ...]
    # Portal / system identity

    document_archetype: DocumentArchetype
    # Student ID
    student_id_label: str               # "Student ID", "UID", "N-Number", "UMID", "UT EID"
    student_id_format: str              # regex, e.g. r"\d{9}", r"N\d{8}", r"[a-z]{2,4}\d{3,5}"
    student_id_prefix: str = ""
    student_id_starts_with: str = ""    # UCLA: "9", UMich: any 8-digit
    # Term system
    term_seasons: tuple[str, ...] = ("Spring", "Summer", "Fall")
    term_system: str = "semester"       # "semester" or "quarter"
    # Branding
    primary_color: str = "#1a1a1a"
    accent_color: str = "#888888"
    # PDF metadata

    pdf_creator: str = "PeopleSoft Enterprise"

    crn_label: str = "Class Nbr"

Student ID Generation by Institution

import random, re

def _generate_student_id(rng: random.Random, institution: Institution) -> str:
    """
    Generate a student ID matching the institution's verified format.
    """
    iid = institution.id

    if iid == "psu":
        # 9-digit numeric, no prefix
        return "".join(str(rng.randint(0, 9)) for _ in range(9))

    elif iid == "ucla":
        # Must start with 9, then 8 more digits
        tail = "".join(str(rng.randint(0, 9)) for _ in range(8))
        return f"9{tail}"

    elif iid == "nyu":
        # N + 8 digits
        digits = "".join(str(rng.randint(0, 9)) for _ in range(8))
        return f"N{digits}"

    elif iid == "umich":
        # 8-digit UMID — avoid leading zeros
        return str(rng.randint(10000000, 99999999))

    elif iid == "ut_austin":
        # UT EID: 2–4 lowercase letters + 3–5 digits
        letters = "".join(rng.choice("abcdefghjklmnpqrstuvwxyz")
                         for _ in range(rng.randint(2, 3)))
        digits  = "".join(str(rng.randint(0, 9)) for _ in range(rng.randint(4, 5)))
        return f"{letters}{digits}"

    else:
        # Generic fallback
        pattern = institution.student_id_format
        n_match = re.findall(r"\\d\{(\d+)\}", pattern)
        n = int(n_match[0]) if n_match else 9
        return institution.student_id_prefix + "".join(
            str(rng.randint(0, 9)) for _ in range(n)
        )


def _generate_student_email(profile_name: str,
                             institution: Institution,
                             rng: random.Random) -> str:
    """Institution-accurate email format."""
    first, last = profile_name.split()[0].lower(), profile_name.split()[-1].lower()

    if institution.id == "ut_austin":
        # UT email = EID@my.utexas.edu — derive from student_id
        return f"{profile_name}@my.utexas.edu"  # caller passes EID here
    elif institution.id == "umich":
        # uniqname@umich.edu — typically firstinitiallastname
        uniq = (first[0] + last)[:8]
        return f"{uniq}@umich.edu"
    else:
        # Standard: firstname.lastname@domain or firstinitiallastname@domain
        return f"{first}.{last}@{institution.domain}"

def _current_term_for_institution(
    institution_id: str,
    as_of: date | None = None,
) -> tuple[str, date, date]:
    """
    Returns (term_label, term_start, term_end) for the term
    containing 'as_of' (defaults to today), for the given institution.
    UCLA Winter/Spring quarter names are distinct from other schools.
    """
    d = as_of or date.today()
    cal = _TERM_CALENDARS.get(institution_id, _TERM_CALENDARS["psu"])
    for label, (start, end) in cal.items():
        if start <= d <= end:
            return label, start, end
    # Inter-term: find nearest upcoming
    future = {k: v for k, v in cal.items() if v[0] > d}
    if future:
        nearest = min(future.items(), key=lambda x: x[1][0])
        return nearest[0], nearest[1][0], nearest[1][1]
    # Fallback: last term in calendar
    last = list(cal.items())[-1]
    return last[0], last[1][0], last[1][1]
